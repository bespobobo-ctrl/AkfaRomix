# AKFA HR Portal - Enterprise Edition

Professional HR and Management system for AKFA Romix.

## 🚀 Getting Started
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Build for production: `npm run build`

## 📁 Directory Structure
- `src/js/core/`: Central system components (Supabase, Auth UI)
- `src/js/services/`: Business logic modules (Auth, HR)
- `src/js/components/`: Reusable UI components
- `src/js/pages/`: Logic for specific dashboard pages
- `src/pages/`: HTML entry points for dashboards
- `src/css/`: Global styles and tokens
- `database/`: Database schema and migrations

## 🛠 Tech Stack
- Vite (Build tool)
- Supabase (Backend as a Service)
- Vanilla JS (Frontend Logic)
- Lucide Icons (Visuals)
- GSAP (Animations)
